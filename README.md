# 수시 면접 준비실

고등학교 3학년 담임이 반 학생의 수시 면접을 지도할 때 쓰는 한 장짜리 웹앱입니다. 나이스에서 내려받은 학교생활기록부를 넣으면 학년별로 정리하고, 학생부 근거만으로 예상질문지를 만들고, 모의면접을 진행합니다.

## 기능

- **나이스 학생부 불러오기** — PDF · HWP · HWPX · 엑셀 파일을 브라우저 안에서 읽어 학년별 세특 · 창의적 체험활동 · 행동특성 및 종합의견으로 나눕니다. 인적·학적사항, 출결, 성적표 숫자, 매 쪽 머리글(학교명·성명)은 뺍니다.
- **예상질문지** — 한 줄 서사, 지뢰 항목, 영역별 질문 15~20개, 꼬리질문, 키워드와 답변 뼈대. 질문의 약 50%를 3학년, 30%를 2학년 기록에서 냅니다.
- **진로 분석** — 학생부 전체를 근거로 학생의 진로를 한 줄로 정하고, 학년별 근거와 지원 학과와의 연결 정도를 보여 줍니다.
- **근거 인용 대조** — AI가 인용한 학생부 문장을 원문과 대조해 '원문에 없음'을 표시합니다.
- **모의면접** — 한 문항씩 묻고 꼬리질문을 던지며, 세 문항마다 잘한 점 · 고칠 점 · 블라인드 위반 여부를 피드백합니다.
- **블라인드 점검** — 출신 고교명, 부모 직업, 공인 어학 성적, 교외 수상, 논문, 해외 활동, 자격증 표현을 찾아 표시합니다.
- **반 현황표** — 면접일이 가까운 순, 같으면 지뢰 항목이 많은 순으로 우선 지도 순위를 매깁니다.

## 개인정보

- 학생부 파일은 **브라우저 안에서만** 읽습니다. 서버로 보내지 않습니다.
- 학생 데이터는 claude.ai에서 열었을 때 **선생님 계정의 개인 저장 영역**에 저장되며 다른 사람에게 보이지 않습니다. 그 밖의 환경에서는 그 브라우저에만 저장됩니다.
- 학생부 내용은 예상질문지를 만들거나 모의면접을 할 때만 AI로 전송됩니다.
- **이 저장소에는 학생 데이터가 들어 있지 않습니다.** 코드만 있습니다.

## 실행

AI 기능(예상질문지 · 모의면접)은 claude.ai Artifact 환경에서만 동작합니다. 정적 호스팅에 올리면 파일 정리, 반 현황표, 블라인드 점검만 쓸 수 있습니다.

```bash
node build.js        # app.html → index.html (문서 뼈대를 씌운 정적 페이지)
```

## 구조

| 파일 | 내용 |
| --- | --- |
| `app.html` | 앱 본문. claude.ai Artifact에 올리는 원본이며 모든 코드가 여기 있습니다. |
| `build.js` | `app.html`에 문서 뼈대를 씌워 `index.html`을 만듭니다. |
| `index.html` | 정적 호스팅용 결과물. 직접 고치지 말고 `build.js`로 다시 만드세요. |

## 만든 방식

Claude Code로 만들었고, 면접 지도 규칙은 수시 면접 코치 스킬을 따릅니다.
